🏎️ Fórmula 1 – Plataforma Web

Aplicación web para consultar información de la temporada de Fórmula 1, incluyendo carreras, circuitos, pilotos y escuderías, con estadísticas y datos históricos.

⚙️ Tecnologías

Backend: Java • Spring Boot • JPA/Hibernate • MySQL
Frontend: Angular • TypeScript • CSS

🚀 Instalación y ejecución
🔧 Backend

Clonar el repositorio

git clone <url-del-repositorio>


Crear la base de datos en MySQL:

CREATE DATABASE formula1_jpa;


Configurar application.properties con tus credenciales.

Ejecutar el backend:

./mvnw spring-boot:run


👉 API disponible en: http://localhost:8080/api

💻 Frontend

Entrar a la carpeta del frontend:

cd formula1-frontend


Instalar dependencias:

npm install


Ejecutar la app:

ng serve


👉 Acceso desde el navegador: http://localhost:4200

📄 Funcionalidades principales

Ver calendario y próximas carreras.

Consultar circuitos, pilotos y escuderías.

Acceder a estadísticas y datos históricos.
